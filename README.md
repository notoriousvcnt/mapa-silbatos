# MAPA-Silbatos

Código de dos proyectos del Museo de Arte Popular Americano (MAPA) que convierten
el soplido de un silbato, captado por el micrófono, en sonido y señales de control.
El audio se diseña en Max/RNBO y se ejecuta en el navegador.

| Carpeta | Proyecto |
|---|---|
| [`SilbatoWeb-Audio/`](SilbatoWeb-Audio/) | Sampler de silbatos para el catálogo web de instrumentos de la colección MAPA ([instrumentosmapa.uchile.cl](https://instrumentosmapa.uchile.cl/)). |
| [`AppSilbatoExposición/`](AppSilbatoExposición/) | Instalación interactiva de la exposición "Tecnologías para tocar lo invisible" (enero–mayo 2025). |

Cada proyecto incluye una carpeta `rnbo/` con los parches fuente (Max/RNBO) y
sus instrucciones de uso en su propio README.

## Créditos
